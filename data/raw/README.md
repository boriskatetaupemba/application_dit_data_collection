# Données brutes Web Scraper

Déposez dans ce dossier les exports **non nettoyés** produits avec l'extension
Chrome Web Scraper. Les noms recommandés sont :

- `books_webscraper_raw.csv`
- `gaaraas_webscraper_raw.csv`

Ces fichiers ne sont pas générés par Selenium et ne doivent pas être remplacés
par les données nettoyées. Ils sont ignorés par Git par défaut afin d'éviter de
versionner de gros exports ou des données non validées.
